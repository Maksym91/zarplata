# Скрипт обробки процентівки та відомості

## Опис
Скрипт автоматизує обробку даних між таблицями процентівки та відомості з ексель файлів.

## Функціональність
- Зчитує дані з `Процентівка.xlsx` та `Відомість.xlsm`
- Знаходить відповідності за прізвищами (колонка D7)
- Підставляє дані: дата з, дата по, тарифний розряд, розмір премії
- Обробляє дублікати прізвищ з процентівки, додаючи їх як окремі рядки
- Створює окремий файл з відсутніми записами

## Встановлення
```bash
pip install pandas openpyxl
```

## Використання
```bash
python main.py
```

## Результати
Скрипт створює два файли:
- `Відомість_оновлена_[timestamp].xlsx` - оновлена відомість з даними з процентівки
- `Відомість_нові.xlsx` - записи, які є в процентівці але відсутні в відомості
